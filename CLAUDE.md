# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Context

PUC academic project: Análise Exploratória de Dados (EDA). Course: Ciência de Dados e Big Data, Unidade II.

## Assignment Requirements

**Deliverables:**

- PDF report (scientific format, with dataset link/reference)
- Treated dataset (CSV or Excel)
- Video ≤5 min (team intro, dataset context, results, slides)
- Separate text file with all LLM prompts used

**Minimum requirements:**

- ≥4 statistical methods (mean, median, mode, std dev, percentile)
- ≥3 visualizations (Excel, PowerBI, GapMinder, or Tableau)
- Dataset from 2025 or 2026
- Data-oriented problem statement (specific attributes, not vague themes)

## Rule

**All LLM prompts used throughout the project must be documented.** under @prompts.md

Ignore adjustment prompts, like "fix it", "change that", "implement the plan"
Document big change prompts or rule prompts, like planning prompts or "This must be x way" or "This must no be made"
